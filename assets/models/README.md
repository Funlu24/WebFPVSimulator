# 3D models

`low-poly-medieval-house.glb` is **Houses** by Quaternius, downloaded from
Poly Pizza. It is a 3,492-triangle GLB and is released as CC0 (public domain):
https://poly.pizza/m/vCoDG5hFyI

The city map loads it with Three.js `GLTFLoader` and uses scaled clones for the
city-centre house placements. The existing procedural house remains the
fallback if the GLB cannot load.
